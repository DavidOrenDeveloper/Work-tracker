# יומן עבודה — ניהול ומעקב

אפליקציית ווב (PWA) לניהול ותיעוד עבודות אתר. עובדת לגמרי בצד הלקוח — אין שרת, אין
חשבון, אין תלות בשירות חיצוני. כל הנתונים נשמרים בדפדפן/בטלפון שלך בלבד (IndexedDB).

## הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | כל האפליקציה — עיצוב, לוגיקה, כל המסכים. הקובץ המרכזי, זה שנפתח בדפדפן. |
| `manifest.json` | מגדיר איך האפליקציה מתנהגת כשמתקינים אותה למסך הבית בטלפון (שם, אייקון, צבעים). |
| `service-worker.js` | קובץ טכני שמאפשר "התקנה" אמיתית של האפליקציה (PWA). **לא שומר קאש** בכוונה — כל פתיחה טוענת את הגרסה העדכנית מהאינטרנט. |
| `icon-192.png`, `icon-512.png` | אייקוני האפליקציה למסך הבית. |

> **למה הכל לא בקובץ אחד?** לוגיקת האפליקציה כן נמצאת כולה ב-`index.html` אחד (זה
> נכון ומומלץ לאפליקציה כזו — בלי שרת, בלי שלב build). שאר הקבצים (manifest, אייקונים,
> service worker) הם קבצי תמיכה סטנדרטיים שכל PWA צריך כדי להתקין יפה על הטלפון.

## איך מעלים ל-GitHub ומפרסמים (GitHub Pages)

1. ב-GitHub: **New repository** → תן שם (למשל `work-tracker`) → Create repository.
2. בעמוד הריפו הריק: **uploading an existing file** (או גרירה) → גרור את כל 5 הקבצים
   מהתיקייה הזו (`index.html`, `manifest.json`, `service-worker.js`, שני קבצי ה-PNG) →
   Commit changes.
3. **Settings** → בתפריט הצד **Pages** → תחת "Build and deployment" בחר
   **Deploy from a branch** → Branch: `main`, Folder: `/ (root)` → Save.
4. אחרי כדקה תופיע כתובת בסגנון `https://USERNAME.github.io/work-tracker/` —
   זו הכתובת הקבועה של האפליקציה שלך.
5. פתח את הכתובת בטלפון (כרום/ספארי) → תפריט הדפדפן → **הוסף למסך הבית /
   התקן אפליקציה**. מעכשיו יש לך אייקון אפליקציה רגיל בטלפון.

## מה קורה כשאני מוסיף פיצ'רים בעתיד?

1. ערוך/עדכן קבצים בריפו (דרך GitHub ישירות, או `git push` אם אתה עובד מקומית).
2. GitHub Pages בונה מחדש אוטומטית תוך כ-30–60 שניות מכל עדכון.
3. **בפעם הבאה שתפתח את האפליקציה בטלפון (עם אינטרנט), היא תיטען מחדש מהשרת
   ותציג את הגרסה העדכנית אוטומטית** — אין צורך להסיר ולהתקין מחדש. זה בזכות
   כך שה-`service-worker.js` **לא שומר קאש בכלל** בכוונה (כתוב את זה בפירוש בקובץ) —
   הבחירה הזו מבטיחה עדכניות על פני יכולת עבודה אופליין מלאה.
4. שים לב: הנתונים שלך (עובדים, דיווחים וכו') נשמרים ב-IndexedDB של הדפדפן/הטלפון
   שלך, נפרד לגמרי מהקוד עצמו — עדכון קוד לא מוחק ולא נוגע בנתונים השמורים שלך.

## גיבוי

מומלץ להשתמש בכפתור "ייצוא גיבוי" במסך ההגדרות מדי פעם (למשל פעם בשבוע), ולשמור
את קובץ ה-JSON שיורד במקום בטוח (Drive/Dropbox). זה הביטוח שלך למקרה שמתחלף טלפון,
מוחקים את הדפדפן, וכו' — מכיוון שהנתונים חיים רק במכשיר הנוכחי.
